# SpendWise - Expense Manager

SpendWise is a Java Swing desktop application for tracking income and expenses.

## Features
- Add income and expense transactions
- View transaction history
- Calculate total income and expenses
- View the current balance
- Delete transactions
- Dark-themed graphical interface

## Technologies Used
- Java
- Java Swing
- AWT
- ArrayList
- LocalDate

## Requirements
- Java Development Kit (JDK)

## How to Run
1. Open PowerShell in the project folder.
2. Compile the program:
   javac SpendWise.java
3. Run the application:
   java SpendWise

## Note
Transactions are stored in memory and are not permanently saved after closing the application.
